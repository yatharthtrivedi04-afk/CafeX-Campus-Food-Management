# CafeX Terminal Project

Simple terminal-based campus cafe ordering and management system. Requires Python 3 only.


## Run on macOS / VS Code
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: `python3 main.py`

The CSV files are created automatically in the `data` folder on first run.


## Demo logins
- F&B manager: `fbmanager` / `fbmanager123`
- GreenOx: `greenox` / `greenox123`
- Subway: `subway` / `subway123`
- Domino's: `dominos` / `dominos123`
- Southern Stories: `southern` / `southern123`

Customers can register from the opening menu.

## Features
- Outlet browsing and menu display
- Customer registration/login
- Orders: takeaway or dine-in; stock decreases automatically
- Seat reservation requests
- Customer activity/history
- Outlet managers: menu items, stock, orders, reservations, completion
- F&B manager: outlet timings, status, all orders and reservations

Educational demo only: passwords are stored in plain text CSV.
